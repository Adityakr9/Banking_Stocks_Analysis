# 📊 Banking Stocks Analysis

## 📌 Project Summary

The **Banking Stocks Analysis** project is a detailed financial analysis of major Indian banks' stock performance.

Using historical stock data extracted from Yahoo Finance, this project analyzes:

- Stock price trends  
- Trading volumes  
- Volatility patterns  
- Correlation between banking stocks  

The goal is to provide insights into the financial performance and market behavior of leading Indian banks.

---

## 🧠 Project Description

The project begins with data extraction using the `yfinance` library to download historical stock data.

The dataset includes:

- Daily Open, High, Low, Close prices  
- Adjusted Close prices  
- Trading Volume  

---

## 🔍 Key Analytical Steps

### 📈 1. Time Series Analysis
- Plotted stock prices and trading volumes over time  
- Identified trends and price fluctuations  
- Used line charts for visualization  

### 📊 2. Moving Averages
- Calculated:
  - 20-day (Short-term)
  - 50-day (Medium-term)
  - 100-day (Long-term)
- Helps identify:
  - Trend direction  
  - Potential buy/sell signals  

### 📉 3. Daily Returns Analysis
- Computed daily percentage change in stock prices  
- Analyzed volatility patterns  
- Categorized returns using visualizations (pie charts)  

### 🔗 4. Correlation Analysis
- Evaluated correlation between daily returns of different banks  
- Helps understand diversification potential  
- Visualized using heatmaps
